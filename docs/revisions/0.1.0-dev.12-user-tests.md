# Revision 12 acceptance checks

- Install **Orqa Print** with **Install SolidWorks Add-in.cmd**; confirm an Orqa
  tab on a SolidWorks part. Drawing/assembly documents should not export.
- Launch the selected Orqa revision and connect accounts. Confirm the dialog
  shows your connected printers and the correct nozzle profiles. Confirm saved
  materials and compatible built-in/user process presets appear.
- Load a part into Orca. Check dimensions, units and active configuration.
  Edit the part and load it again: its prior imported copy should be replaced.
  Other objects should remain.
- Change process and filament settings in Orca without saving presets. Export
  another part with **Current in Orca** selected in both lists. Confirm both sets
  of edits carry over and no named presets were created.
- For AMS or multi-extruder printers, use **Load in slicer**, then the normal
  slicer print flow. Background Print currently requires an external spool and
  a single-extruder profile.
- With the printer ready and its external spool correctly loaded, minimize Orca
  and press Print on a small known part. Confirm Orca stays minimized, the open
  project stays intact, and Device reports the intended printer receiving the
  job. Check the physical first layer before leaving the printer unattended.
- If sending times out, check Device before retrying. Confirm it does not
  automatically send the job twice.
- Close/reopen Orca: prior unsaved session choices should not become saved
  presets, and old queued requests should not execute in the new session.

Development checks cover compilation, mock mailbox behavior and real CLI
STEP-to-3MF slicing/validation. SolidWorks UI/CAD-export and hardware acceptance
remain unverified until the checks above are performed.
