# 0.1.0-dev.13 — Fast Start volume warning

Before a model-based print, Fast Start machine profiles now show a warning at
**10 cm³ or greater**. Cancel is the default; Print anyway explicitly continues.
The warning names the profile, shows the solid model volume, and recommends the
normal machine profile for finished parts. Closing the dialog cancels. There is
no permanent suppression option. Loading, exporting and slicing alone do not warn.

Detection reads the edited machine profile name and resolved startup G-code.
Copies or renamed profiles retain detection through the ORQA FAST START marker.
Ordinary profiles and smaller parts proceed normally. Unknown/invalid volume
prompts for review instead of bypassing the warning.

Orqa calculates volume for printable copies on the requested plate, including
scaling and mirroring. All-plate sends sum the printable copies. Positive solid
bodies are used; overlapping bodies and negative-volume cuts can make this a
conservative estimate. This is model volume, independent of infill and supports.
The gate covers normal Bambu/LAN print submission, native multi-machine sends,
Flashforge cloud Print, and the legacy print-host send route. Printing existing
G-code from a printer's storage is outside this model-based check.

SolidWorks add-in **0.1.0.15** measures the active part/configuration using
SolidWorks mass properties with system units, with selections temporarily
cleared and restored. It warns before STEP export and background slicing, then
passes a check acknowledgement bound to that prepared settings token. The new
bridge rejects unchecked Fast Start background requests from older add-ins.
Use the new slicer revision and add-in together.

Validation: native detection/threshold tests, SolidWorks unit conversion,
threshold/unknown-volume and mock print-protocol tests, and native/add-in builds.
No physical print is submitted during validation. Live CAD and printer workflows
still require user acceptance testing.

Restart Orqa after saving any current project. Install the updated SolidWorks
add-in through Install SolidWorks Add-in.cmd. Settings/accounts continue to use
revision 1's shared settings; revision 12 remains available for rollback.
