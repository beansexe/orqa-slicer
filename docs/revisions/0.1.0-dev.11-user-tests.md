# Multi-print user checks

1. Open a small one-material plate and enable Multi-print beside the Print button.
2. Add the X2D with its installed nozzle profile. Add the Adventurer 5M for the
   same source plate. Confirm both cards are listed on the left in Prepare and
   Preview and Print to all printers is the default Print/dropdown action.
3. Set different process or filament settings on each card. Switch back and
   forth and confirm the settings stay with the right printer. Slice a card
   and verify Preview uses that printer's bed and toolpath.
4. Use a deliberately unsuitable plate or material on one target. Its card
   should show a validation/slicing error and the batch must not send it.
5. With suitable plates and both printers ready, use Print to all printers.
   Review each vendor confirmation and mapping. Confirm the actual printer
   receives its own correctly sliced job. Flashforge's Start printing after
   delivery is selected by default in a batch, and can be changed in its dialog.
6. Cancel a send dialog or the remaining batch and confirm no automatic resend
   occurs. Already-started prints should continue.
7. Save the Multi-print workspace, keep both companion files together, reopen
   the source 3MF and load its printer cards. Verify assignments/settings.
8. Toggle Multi-print off and confirm ordinary single-printer printing returns.

Development does not send jobs or control real printers. Report the card name,
printer model and any error screenshot for a failed step.
