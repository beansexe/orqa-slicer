# 0.1.0-dev.7 — Printer firmware update notices

Status: needs testing. Revision 6 cloud print-job submission is user-confirmed.

This revision announces firmware updates reported by the printer services:

- Bambu: fresh printer messages carrying an explicit firmware update flag produce
  a notice in the slicer's Prepare/Preview notification area. Connect the Bambu
  printer through its normal Device view. This applies to the H2S, X1 Carbon,
  and X2D when their service reports an update. Device > Update retains the
  existing Bambu update controls.
- Flashforge: restoring the account or clicking Refresh printer list checks the
  vendor's update notice in that list. The selected printer's Flashforge page
  has a Firmware update row; hover for the vendor's title/details. A notice also
  appears in the Prepare/Preview notification area when an update is reported.
  Review/install Flashforge updates through the printer or vendor slicer.

Repeated identical notices are suppressed for the current application session.
An installed version number alone never implies an update. Flashforge's list
must be refreshed after five minutes to refresh its update indicator; absence
of a notice is not a guarantee that the printer is up to date. The feature does
not download or install firmware. Account sessions and wireless sending use the
same original settings folder as previous revisions.

Close the old preview, open Launch-Slicer.cmd, and restore Flashforge through
Printer accounts. Refresh its printer list and check the Firmware update row.
For Bambu, select a Bambu profile and connect Device. If an update is available,
check the notice and confirm that refreshing does not repeatedly announce it.
If no update is available, ordinary operation should continue quietly. Also try
normal printer selection and cloud sending. Camera playback remains deferred.

Only focused provider-signal, notice-model and account-copy checks, changed-file
source checks, and native build/package startup checks were run. Real update
availability and all printer behavior remain for user testing.
