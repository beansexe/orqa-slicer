# 0.1.0-dev.14 — GitHub workspace and first-run polish

The project now has a private GitHub repository, source history, review branches
and automated Windows source checks. A fresh source checkout has explicit setup
and build instructions. Existing installed revisions and settings stay available.

The slicer changes in this revision improve the Multi-print panel on smaller
windows: Add printer and Load saved cards appear before the card list, with shorter
instructions and a more compact list. Printer routing and print confirmations are
unchanged. Each target still requires its own validated slice and vendor review.

The workspace launchers and revision chooser recognize an independent Git checkout
instead of finding a different installation in a parent folder. Saved source
snapshots still find their owning installed workspace. The SolidWorks installer
explains when its add-in must be built before requesting administrator privileges.
SolidWorks add-in 0.1.0.16 remains the current add-in.

Application update checks now point to the Orqa GitHub releases page when
explicitly requested. Automatic checks no longer offer a stock OrcaSlicer
installer over this customized preview. Printer-profile updates retain their
existing behavior. Downloading and installing an Orqa update remains deliberate.

## Portable package

Extract the entire ZIP into a writable folder and use START ORQA.cmd. This copy
has its own empty data_dir. Complete the normal profile setup and obtain any
required vendor plug-ins separately. No accounts or presets are included. Matching
workspace source, pinned upstream references and notices accompany the runtime.

Keep your existing installation and its data_dir for rollback. Workspace users
can publish/select revision 14 with their existing shared-settings reference.
Downloading the standalone ZIP does not automatically move existing accounts,
install the SolidWorks add-in, or change your selected workspace version.

## Verification and remaining checks

Development verification is recorded in docs/github-migration.md. This is a
preview, with live CAD and printing acceptance still pending. Existing user
evidence confirms X2D cloud printing/video and Flashforge cloud printing and job
controls. Multi-print hardware acceptance, other Bambu models and delayed
Flashforge bed reporting retain their previous status.

Before using this revision for a batch, verify that Add printer is visible at
your normal window size, toggle Multi-print off/on, and follow the saved Multi-print
checklist with a small known project. In SolidWorks, check that closing the chooser
returns focus and Load in slicer opens the exported part. Do not treat source-only
automated tests as proof that a physical job completed.
