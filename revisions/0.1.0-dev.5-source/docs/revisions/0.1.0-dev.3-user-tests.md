# User test results — 0.1.0-dev.3

Evidence: user supplied two screenshots on October 14, 2026 and reported that
the preview looks good so far.

Confirmed from the screenshots:

- The Flashforge device page is accessible and displays the selected Adventurer
  5M, an account-reported ready status, a successful list-refresh message, and a
  recent refresh age. The page identifies the values as an account-list snapshot.
- Choose printer displays all four requested machine models: Bambu H2S, X1
  Carbon, X2D, and Flashforge Adventurer 5M.
- Selecting the Flashforge row offers matching enabled nozzle profiles for
  0.25, 0.4, 0.6, and 0.8 mm.

The screenshots do not establish which navigation entry opened the page,
whether Refresh was clicked manually, which nozzle is installed, whether a
profile choice was committed, or whether switching back to Bambu succeeded.
LAN configuration, wireless submission, a physical print, logout isolation,
and retention across another restart remain unconfirmed.

Follow-up: the user confirmed that choosing the installed nozzle profile and
clicking Use printer / profile shows the matching profile in Prepare. Committed
profile selection is therefore user-confirmed. The installed nozzle diameter
was not specified.

Flashforge live monitoring and cloud job submission are not implemented in this
revision. Bambu video remains deferred. The revision remains **needs testing**;
these results confirm the displayed page and chooser rather than complete
printer operation. No account identities, printer nicknames, credentials, logs,
or session files were saved with this report.
