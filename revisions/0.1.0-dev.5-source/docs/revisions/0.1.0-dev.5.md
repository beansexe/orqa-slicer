# 0.1.0-dev.5 — Correct single-material cloud-send detection

Status: needs testing.

The send dialog now reads actual positive filament usage from the current slice.
The old check read a cache populated when loading sliced 3MF files, so a normal
single-material slice could be rejected. Material type/color are resolved from
the selected filament settings when absent from the cached metadata. Multiple
used filaments remain unsupported; missing material settings have their own error.

Close the current preview, then open Launch-Slicer.cmd after revision 5 is selected.
Use the same printer/nozzle and single-material plate, slice it, open Preview,
then click Send current plate via cloud. The confirmation dialog should appear.
Leave Start printing after delivery unchecked for the first delivery test.
Existing accounts/presets use the original revision 1 settings folder. Cloud
operation and physical printing still require user validation.
